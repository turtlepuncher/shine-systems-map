# Estudio Shine — systems map

A single self-contained page describing how Estudio Shine (Barcelona) runs a music
school, a rehearsal-room rental and an instrument rental on one platform.

Published at https://mapa.shinemusicschool.es

Static HTML. No build step, no dependencies, no data: the page makes no network
calls of its own and contains no credentials, endpoints, addresses or customer
information. The control-panel screenshots were taken from a throwaway copy of the
system seeded with invented people.
